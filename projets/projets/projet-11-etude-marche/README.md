# Projet 11 – Étude de marché stratégique

## Contexte
Mission d’analyse réalisée dans le cadre d’une étude de marché.
Objectif : produire une analyse data-driven permettant d’identifier des opportunités stratégiques et d’orienter la prise de décision.

## Objectif du projet
- Analyser un marché cible
- Identifier des segments porteurs
- Mesurer les tendances et dynamiques concurrentielles
- Proposer des recommandations basées sur les données

## Méthodologie

### 1. Exploration des données
- Nettoyage et préparation
- Analyse descriptive
- Identification des variables clés

### 2. Analyse approfondie
- Segmentation
- Analyse comparative
- Détection de tendances

### 3. Recommandations
- Positionnement stratégique
- Opportunités de développement
- Axes d’amélioration

## Visualisations produites
- Graphiques comparatifs
- Segmentation client / marché
- Analyse temporelle
- Indicateurs synthétiques

## Livrables
- Notebook d’analyse (R / Python)
- Visualisations graphiques
- Synthèse stratégique
- Présentation orientée décision

## Compétences mobilisées
Analyse exploratoire de données  
Segmentation et interprétation  
Data storytelling  
Approche orientée décision stratégique
