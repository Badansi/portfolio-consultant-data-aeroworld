Projet Détection Faux Billets

Modèle ML supervisé

Objectif

Détecter automatiquement les faux billets en utilisant des modèles de Machine Learning supervisés.

Méthodologie

  • Collecte et nettoyage des données sur billets réels et faux
  • Entraînement d’un modèle Random Forest
  • Validation du modèle et évaluation performance

Résultats

  • Modèle avec 98% d’accuracy
  • Notebook reproductible et rapport explicatif pour le client

Stack Technique

Python, R, Machine Learning, DataViz
