Projet 10 – DWFA | Priorisation des actions d’accès à l’eau potable

Fichier Tableau (.twbx) Présentation (.pptx)

Contexte : Mission de conseil réalisée pour l’ONG DWFA (Drinking Water For All). Objectif : cadrer un tableau de bord décisionnel pour prioriser les investissements en matière d’accès à l’eau potable.

Objectif : Concevoir un dashboard stratégique permettant d’identifier les pays en difficulté, prioriser les actions et suivre les progrès.

Dashboards conçus : Diagnostic global, spécialisation par domaine DWFA, suivi et recommandations.

Livrables : Dashboard interactif, note de cadrage PDF, présentation synthétique.

Projet 11 – Étude de marché stratégique

Notebook (.ipynb) Notebook PCA/Clustering (.ipynb) Présentation (.pptx)

Contexte : Mission d’analyse dans le cadre d’une étude de marché pour identifier des opportunités stratégiques.

Objectif : Analyser un marché cible, identifier les segments porteurs et proposer des recommandations basées sur les données.

Méthodologie : Exploration des données, analyse approfondie, recommandations.

Livrables : Notebook d’analyse, visualisations graphiques, synthèse stratégique.

Projet 12 – Détection de faux billets (Machine Learning)

Notebook Python/R (.ipynb) Présentation (.pptm)

Contexte : Mission pour l’Organisation nationale de lutte contre le faux-monnayage (ONCFM) pour distinguer billets vrais/faux.

Objectif : Créer un modèle performant capable d’identifier un maximum de faux billets.

Méthodologie : Analyse exploratoire, préparation des données, modélisation, évaluation, déploiement.

Livrables : Notebook d’analyse exploratoire, notebook prédictif, support de présentation, recommandations.
